# Assembly

### Mechanical Component + Chassis Integration

* Drill holes (needs more detail)
* Sand Chassis with 220 grit, lightly scuff all areas
* Sand one side of 1/8" thk Chassis Plate with 220 grit
* Place appropriate amount of DP460 on sanded area on chassis
* Place chassis plate on area with adhesive, line up holes.
* Install component with appropriate hardware, and torque down.
  * Use Filleting Wax on face of component and all hardware so DP460 doesnt cure on it.
