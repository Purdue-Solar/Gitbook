# Front Suspension

Front suspension most often uses a double wishbone design. The alternative is usually the MacPherson strut, but double wishbone allows for more fine-tuning of geometry.

Front suspension is rather complex because of double wishbone, because it has to integrate with steering, and because there are two front wheels that are mirrors of one another. There is an awful lot to learn about camber, caster, instance centers, spring rates, slip angles, and more; the complexity, however, is easily transferrable to racecar and commercial car suspension.
