# Ansys Installer Guide

Navigate to: [https://download.ansys.com/currentReleases](https://download.ansys.com/currentReleases). You may need to create an account. Navigate to **Primary Packages**. For FEA, download the **Structures** package. For CFD, download the **Fluids** package. Keep in mind that each package is roughly 60 GB. The installation will take a while, so make sure you have a stable connection before proceeding. This guide will use the Structures package as an example. &#x20;

<figure><img src="../../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure>

Once you have downlaoded and extracted the zip file, open **setup**.&#x20;

<figure><img src="../../.gitbook/assets/image (175).png" alt=""><figcaption></figcaption></figure>

Click **Install Ansys Products**.&#x20;

<figure><img src="../../.gitbook/assets/image (177).png" alt=""><figcaption></figcaption></figure>

Proceed through the installer as usual. Technically, the only required applications (for **Sturctures**) are 3D Design and Structures. The rest of these are quality of life/add=ons. If you are low in disk space, you are free to uncheck them.&#x20;

<figure><img src="../../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure>

Automatic interface configuration is good. If you have custom settings you would like to use, you may set them now.&#x20;

<figure><img src="../../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure>

Once the installation is complete, open the **Ansys Licensing Settings** application.&#x20;

<figure><img src="../../.gitbook/assets/image (178).png" alt=""><figcaption></figcaption></figure>

Navigate to **Web Licensing** > **Products** > **Roaming.** You will need to change the search setting from installation to **User** (top right corner). When you sign it, it may prompt you to register your account. Use your Purdue email. The company name is **Purdue University West Lafayette**. The address is **610 Purdue Mall
&#x20;West Lafayette, IN 47907.** The customer ID number is **1203689.**&#x20;

<figure><img src="../../.gitbook/assets/image (179).png" alt=""><figcaption></figcaption></figure>

You should be able to check out licenses now! I woudl recommend setting the expiration date of your license check out to be the end of your work session. This way, other people will be able to use them later!&#x20;

<figure><img src="../../.gitbook/assets/image (180).png" alt=""><figcaption></figcaption></figure>

To double check that you are using PSR's Ansys licensing, the top bar should read **\[Ansys Academic Research Mechanical (1 task) - Shared Web]**. If it reads something use, then it is not using the correct license. If that is the case, please speak with your system lead or Chief Engineer.&#x20;

Thank you for following this guide! If there are any errors, please let me (Kira) know :)
