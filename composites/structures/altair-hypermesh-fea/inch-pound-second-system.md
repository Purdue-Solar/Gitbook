# Inch Pound Second System

#### What is IPS?

Unfortunately the United States uses the Imperial System, thus [Mechanical](https://app.gitbook.com/s/UuRMvpyeM6qdlkjmzeYV/mechanical) uses Imperial units for machining reasons. Because we share a CAD system with Mechanical, we also need to use the Inch Pound Second system, named so because it is a system based on the fundamental length of an inch, force of a pound, and time of a second.&#x20;

To be more specific, we use the Gravitational IPS system where pounds are a force, compared to the Absolute IPS system where pounds are a mass. This creates the unintuitive effect that we use slinches for mass, which are equivalent to $$\frac{\text{lbf}\cdot \text s^2}{\text{in}}$$.&#x20;
